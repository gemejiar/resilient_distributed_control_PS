# quick_ref.md — Referencia rápida del usuario

**Propósito:** Cheat sheet de una página. Leer en sesiones cortas cuando no hay tiempo para cargar todo el contexto.
**Cuándo usar:** Al inicio de cualquier sesión, antes de responder.
**Cuándo no usar:** No es suficiente para tareas complejas de revisión o diseño. En esos casos, leer también expertise_map.md y el proyecto activo relevante.
**Actualizar:** Solo si cambia el rol, afiliación o prioridades del usuario.
