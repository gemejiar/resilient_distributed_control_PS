# Agents Catalog

## Core roles

| Role | Responsibility | Required |
|---|---|---|
| STED Integrator | Gate control, artifact minimization, conflict resolution | Yes |
| Execution agent | Performs bounded edits or analysis inside current gate | No |
| Reviewer/auditor | Verifies evidence, writing, code, or methodology when needed | No |

## Rule
Do not create one permanent file per agent unless the workflow truly requires it.
