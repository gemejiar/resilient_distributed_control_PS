# IEEE / Elsevier Paper Architect

Install `SKILL.md` in:

```text
.agents/skills/ieee-elsevier-paper-architect/SKILL.md
```

Copy the `templates/` files into the project only when needed. This package is designed
to coexist with STED-RW Lean. `plan_maestro.md` remains the project source of truth.
The skill assumes a single manuscript file at `paper/main.tex` unless the project
already uses a different path.

`templates/` contains: `paper_blueprint.yaml` and `claim_evidence_matrix.csv`
(G1 scope/claim scaffolds, sections 5.1–5.2); `section_blueprints.md` and
`submission_readiness.md` (pre-submission planning and audit, sections 5.3–5.4);
`cover_letter.md` (section 5.5); and `revision_response_matrix.md` and
`declarations_block.md` (post-submission reviewer response and end-matter
declarations, sections 8.12 and 15).
