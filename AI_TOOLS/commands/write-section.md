Ayuda a redactar o reescribir una sección de artículo científico en estilo journal (IEEE o Elsevier).

Sigue el SOP en `02_routines/sop_scientific_writing.md`.
Usa `03_templates/template_journal_paragraph.md` para párrafos individuales.
Consulta `00_profile/writing_style.md` para el estilo requerido.

Solicita al usuario:
1. ¿Qué sección? (Introduction, Methods, Results, Discussion, Conclusion, Abstract)
2. ¿Tienes un borrador existente o es desde cero?
3. ¿Idioma? (Inglés por defecto para papers)
4. ¿Hay restricciones de extensión?

Produce texto listo para copiar. Marca entre corchetes [REVISAR: motivo] cualquier fragmento que requiera verificación del usuario (datos, citas, valores numéricos).
