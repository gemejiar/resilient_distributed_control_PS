# Scientific Research Template — STED-RW Lean

Plantilla mínima para proyectos científicos y técnicos asistidos por agentes IA.

## Inicio

1. Complete `plan_maestro.md`.
2. Lea `AGENTS.md`.
3. Cree únicamente las carpetas necesarias para el proyecto.
4. Registre decisiones metodológicas importantes en `ops/sted/decision_log.md`.
5. Use trazabilidad solo cuando claims o evidencia lo requieran.

## Archivos principales

- `AGENTS.md`: reglas compartidas para agentes.
- `plan_maestro.md`: fuente de verdad del proyecto.
- `ops/sted/traceability_matrix.csv`: trazabilidad de claims/evidencia.
- `ops/sted/decision_log.md`: decisiones metodológicas.
