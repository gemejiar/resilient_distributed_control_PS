# Methodology Rules

- Methodology follows STED-RW Lean phase order: specification, evidence, tests, execution, verification, writing.
- No final methodology should be drafted before scope, claims, and evidence gates are defined in the active project plan.
- If a required project artifact is missing, create a template and mark it `STATUS: PENDING_COMPLETION`.
- If evidence is missing, keep the field as `PENDING_EVIDENCE`.
- Methodology text must stay aligned with the active project type: paper, book, software, pipeline, proposal, or review.
