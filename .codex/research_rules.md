# Research Rules

- Every claim must map to evidence, test, or explicit scope limitation.
- Use conservative state labels such as `PENDING_EVIDENCE`, `BLOCKED`, or `REFERENCE_NOT_VERIFIED` when appropriate.
- Prefer one authoritative traceability structure over multiple overlapping matrices.
- When conflicts appear, prioritize reproducible evidence over narrative text.
- Template-level files must remain generic unless the user requests a concrete project instantiation.
