## 4. Open items / risks for the first plant contact (all after `BACKUP_VERIFIED`)
* The adapter and `z_ref_from_system` have **never run on the real case**; they are mock-tested only (`UNTESTED_ON_PLANT`).
* `TDS.test_ok` exists only when `TDS.config.test_init` is enabled (ANDES default): if the E8 configuration disables it, the check will fail by design (unverifiable ⇒ invalid); to be confirmed by reading the configuration in P2.
* `init_tol = 1e-8` for both `f` and `g` is a proposal; earlier stages reported `|f|≈4e-16`, `|g|≈6e-10` on specific candidates — not guaranteed for arbitrary dispatches.
* Callback/event ordering at `t=5 s`, GFM initial residuals and Euler-vs-continuous mismatch remain open (v2 §1.3, §2.2.2).
* Evidence directory `DEC054_runs` is on the same disk/synchronised tree as the originals (not an independent backup).
